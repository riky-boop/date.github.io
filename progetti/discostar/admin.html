Come pubblicare le modifiche
  1. Modifica il catalogo qui: le modifiche restano salvate in questo browser.
  2. Clicca Scarica catalog.js.
  3. Sostituisci il file catalog.js del sito con quello scaricato (stessa cartella di index.html).
  4. Dopo il caricamento il sito pubblico mostra il nuovo catalogo.

CSV: colonne format;artist;title;year;genre;label;price;condition;stock;isNew (separatore ; o ,). Si apre e si modifica con Excel. L'importazione sostituisce l'intero catalogo.
