Configurazione

Collega il database

Per modificare il catalogo direttamente da qui serve un database gratuito Supabase (5 minuti, una volta sola):

  1. Crea un account su supabase.com e un nuovo progetto (regione: Europe).
  2. Apri SQL Editor, incolla il contenuto di supabase/schema.sql e premi Run.
  3. In Authentication → Users crea l'utente dell'amministratore (email + password).
  4. Nello SQL Editor esegui: insert into admins (email) values ('email-amministratore');
  5. In Authentication → Sign In / Providers disattiva Allow new users to sign up.
  6. In Project Settings → API copia Project URL e anon public key in config.js (supabaseUrl, supabaseAnonKey).

Come funziona
  • Ogni modifica viene salvata subito e appare sul sito pubblico al prossimo caricamento della pagina.
  • Prezzo e pezzi si modificano direttamente nella tabella; per il resto clicca Modifica.
  • Discogs: in Modifica premi Cerca su Discogs e scegli l'edizione giusta (con il barcode la ricerca è esatta). Completa da Discogs fa lo stesso per tutti gli articoli senza copertina: abbina da solo quando artista e titolo coincidono, il resto te lo propone da scegliere.
  • Esporta CSV → modifica in Excel → Importa CSV: le righe con un id esistente vengono aggiornate, quelle senza id vengono aggiunte. Nessun articolo viene eliminato dall'importazione.
